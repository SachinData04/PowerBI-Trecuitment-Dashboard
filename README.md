**Recruitment Analytics Dashboard**

**Project Overview**
This project is an interactive Recruitment Analytics Dashboard built using Power BI and Microsoft Excel. The dashboard analyzes recruiter performance, client activity, bill rates, pay rates, placement trends, and quarterly recruitment insights using real-world recruitment data.

**Dashboard Features**
- Recruiter Performance Analysis
- Quarter-wise Bill Rate vs Pay Rate Trends
- Client Activity Analysis
- Funnel Chart Visualization
- Interactive Data Filtering
- Recruitment Status Tracking
- Dynamic Business Reporting

## Tools & Technologies Used
- Power BI
- Microsoft Excel
- Power Query
- Data Visualization
- Business Analytics

## Key Insights
- Identified top-performing recruiters based on client activity
- Compared quarterly trends in bill rates and pay rates
- Analyzed client hiring distribution and recruitment patterns
- Created interactive visual reports for business decision-making
